# Chess Resume

A personal resume website for **Rosmi bin Abd Razak**, MCF National Trainer, chess trainer and tournament arbiter.

This project is submitted for **CSC574 – Assignment 1: HTML Personal Website (Resume)**.

**Live website:** https://rosmiabdrazak.github.io/chess-resume/

## About the Project

The website presents my chess profile in a single page: profile, skills, achievements, experience, certificate, education and a history of chess tournaments I have played in or arbitrated.

It is built with HTML and CSS, with a small amount of JavaScript as a bonus feature.

## Features

- Semantic HTML5 structure (`header`, `nav`, `main`, `section`, `footer`)
- External CSS stylesheet with a consistent colour theme
- Sticky navigation menu that links to each section
- Responsive layout for desktop, tablet and mobile
- Resume sections: Profile, Skills, Achievements, Experience, Certificate, Education and Engagement History
- Images with alternative text, and a link to the National Trainer certificate (PDF)
- Contact links for email, phone, WhatsApp and Telegram
- **JavaScript enhancements**
  - Dynamic greeting that changes with the time of day (morning, afternoon, evening)
  - Dark mode / light mode toggle button

## Technologies Used

| Technology | Purpose |
| --- | --- |
| HTML5 | Page structure and content |

## How to Run Locally

1. Download or clone this repository:
   ```
   git clone https://github.com/rosmiabdrazak/chess-resume.git
   ```
2. Open the `chess-resume` folder.
3. Double-click `index.html` to open it in a web browser.

No installation or build step is needed.
